# Rep-Documentacao
App-Blog

Sistema de blog com área pública e painel administrativo

Tecnologias
- PHP 8
- MySQl
- HTML e CSS

- Funcionalidades

- Front-End: Listar e ler postagens
- Painel admin: login, criar, editar e excluir postagens

  Como executar

  . Instale o XAMPP e inicie o Apache e o MySQL
  . Copiar a pasta app-blog para htdocs
  . Importar o arquivo banco/app.blog.sql no phpMYAdmin
  . Acesse: http://localhost.app.blog
 
   Acesso ao painel admin ( somente para teste )

   - URL: http://localhost.app-blog/admin
   - Usuário: admin@teste.com
   - Senha: 123456

     Estrutura de Pastas

     - /admin: painel administrativo
     - /public: páginas do front-end
     - /css: estilos
     - /inlcudes: conexão com o banco e funções
     - /banco: script SQL
     - /docs: documentação
